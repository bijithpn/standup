# Inter Font Installation

## Quick Download

1. Visit: https://fonts.google.com/specimen/Inter
2. Click "Download family" button
3. Extract the ZIP file
4. Copy these files from the `static` folder to this directory:
   - `Inter-Regular.ttf`
   - `Inter-Medium.ttf`
   - `Inter-SemiBold.ttf`
   - `Inter-Bold.ttf`

## Alternative: GitHub Release

1. Visit: https://github.com/rsms/inter/releases/latest
2. Download `Inter-X.X.zip`
3. Extract and copy the required font files from `Inter Desktop` folder

## Verify Installation

After copying the fonts, this directory should contain:
```
Inter/
├── Inter-Regular.ttf
├── Inter-Medium.ttf
├── Inter-SemiBold.ttf
├── Inter-Bold.ttf
├── README.md
└── download_font.bat
```

## Fallback

If you don't install Inter fonts, the app will fall back to:
- Satoshi (existing font)
- System default font

The app will still work, but the typography won't match the new design system.
